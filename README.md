## Features

- Upload and process documents
- AI chat with your own knowledge base
- Retrieval Augmented Generation (RAG)
- Semantic search using embeddings
- Source citations
- Multi-workspace architecture
- Multiple AI providers
- Streaming responses


## Architecture

Upload Document
↓
Storage
↓
Text Extraction
↓
Chunking
↓
Embeddings
↓
Vector Database
↓
Retrieval
↓
LLM Response
↓
Citations
