# AI Patterns

## Standard AI Flow

User Action

↓

Validate Request

↓

Retrieve Context

↓

Rank Relevant Information

↓

Generate Response

↓

Attach Citations

↓

Store History

↓

Suggest Follow-up Actions

## AI Error Handling

Examples

- Model unavailable
- Retrieval failed
- Context limit exceeded
- Rate limited
- Network failure

Each error should provide a clear explanation and a retry action.
