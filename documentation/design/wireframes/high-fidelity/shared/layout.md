# Shared Layout

## Purpose

Defines the common application layout used across all pages.

---

## Structure

- Top Navigation
- Left Sidebar
- Main Content Area
- Optional Right Context Panel

---

## Layout Rules

- Sidebar remains consistent across pages.
- Header remains fixed.
- Main content scrolls independently.
- Right panel is optional depending on the page.

---

## Content Width

- Default: Fluid
- Maximum readable width for text-heavy pages.
- Tables and dashboards may use full width.

---

## Spacing

Uses spacing tokens from the Design System.

---

## Components Used

- App Shell
- Sidebar
- Top Navigation
- Content Container
- Divider
