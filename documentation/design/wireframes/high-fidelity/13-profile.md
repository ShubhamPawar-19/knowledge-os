# Profile

## 1. Purpose

The Profile page allows users to manage their personal account, preferences, security settings, AI preferences, and workspace memberships.

---

## 2. Primary Users

- Workspace Member
- Workspace Admin
- Organization Owner

---

## 3. User Goals

Users should be able to:

- View profile information
- Edit personal details
- Change password
- Manage profile picture
- Configure AI preferences
- Manage active sessions
- View workspace memberships

---

## 4. Layout

### Top Navigation

- Workspace Switcher
- Notifications
- User Profile

### Profile Navigation

- Personal Information
- Account Security
- AI Preferences
- Sessions
- Workspace Memberships

### Main Content

Displays the selected profile section.

---

## 5. Main Sections

### Personal Information

- Profile Photo
- Full Name
- Email
- Job Title
- Department
- Bio

---

### Account Security

- Change Password
- Two-Factor Authentication
- Active Sessions
- Login History

---

### AI Preferences

- Preferred AI Model
- Response Style
- Language
- AI Memory
- Default Conversation Settings

---

### Workspace Memberships

Displays

- Workspace Name
- Role
- Joined Date

## 7. User Actions

Users can

- Update Profile
- Upload Avatar
- Change Password
- Enable 2FA
- Logout Other Sessions

- Leave Workspace

---

## 8. AI Behavior

AI can

1. Recommend profile completion
2. Suggest AI settings
3. Recommend security improvements
4. Detect unusual login activity
